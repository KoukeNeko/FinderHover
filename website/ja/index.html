    常見問題

    為什麼需要輔助使用權限？

    FinderHover 使用 macOS 輔助使用 API 來偵測你的滑鼠目前指向哪個檔案。這是唯一能夠即時追蹤 Finder 中檔案的方式，且所有資料都在本機處理，不會傳送到任何伺服器。

    為什麼推薦用 Homebrew 安裝？

    因為更新和安裝都很方便。一行指令就能完成安裝，之後只要執行 `brew upgrade` 即可自動取得最新版本，不需要重新下載或手動更換 .app。

    支援哪些 macOS 版本？

    FinderHover 需要 macOS Sonoma 14.0 或更新版本。我們使用了 Sonoma 引入的新 API 來提供更好的效能和穩定性。注意：不支援 macOS 26.4 Beta 1，請更新至 Beta 2 或更新版本。

    會影響系統效能嗎？

    不會。FinderHover 使用 Combine 框架的 debounce 機制，只在滑鼠停留時才處理資料，CPU 使用率幾乎為零。當你不使用 Finder 時，它完全不會消耗系統資源。
